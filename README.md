# 💼 Personal Portfolio

A modern, responsive portfolio website built to showcase my projects, technical skills, certifications, and professional journey as an aspiring Software Engineer and Full Stack Developer.

The portfolio is designed with a clean and minimal UI, focusing on readability, smooth navigation, and a professional presentation suitable for recruiters and hiring managers.

## 🌐 Live Demo

**Portfolio:** https://lokesh-babu-portfolio.netlify.app/

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Smooth scrolling navigation with active section highlighting
- Professional hero section
- Skills categorized by technologies and tools
- Detailed project showcase with GitHub repository links
- Certifications and training with official credential links
- Resume download option
- Modern UI built with reusable React components

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/l0keshbabu/personal_portfolio.git
```

Navigate to the project

```bash
cd personal_portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
